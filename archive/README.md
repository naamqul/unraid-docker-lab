# Archived deployment experiments

This tree preserves completed or superseded deployment experiments outside the
active Komodo stack directories. Files below `archive/` are not registered
production resources and must not be deployed by pointing an existing stack at
them.

An archived workload may be restored only after its images, artifacts, device
assumptions, ports, safety controls, and controller ownership are reviewed. Use
a distinct Komodo Stack and Compose project for any approved restoration.
